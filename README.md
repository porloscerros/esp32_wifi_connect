# esp32_wifi_connect
Logica basica para conectar el _esp32_ a una red wifi, implementando _BT_ para ingresar las credenciales por conexion serie (ver [Serial Bluetooth Terminal](https://github.com/kai-morich/SimpleBluetoothTerminal) o similares). A su vez, el boton `BOOT` (`G0`) eliminara las credenciales 

Basic logic to connect the _esp32_ to a Wi-Fi network, implementing _BT_ to enter the credentials via serial connection (see [Serial Bluetooth Terminal](https://github.com/kai-morich/SimpleBluetoothTerminal) or similar). In turn, the `BOOT` button (`G0`) will delete the credentials
